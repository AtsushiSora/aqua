# AquaNote Prototype

水槽・池の管理、写真投稿、AI分析、飼育ガイド、収益化導線をまとめた静的プロトタイプです。

## 開き方

`index.html` をブラウザで開くと動きます。

## 入っている機能

- 水槽・池の管理ダッシュボード
- 複数の水槽・池の登録と切り替え
- 水槽プロフィールの編集と削除
- 水温、pH、メンテナンス記録の入力とブラウザ保存
- 選択中の水槽・池ごとの管理ログ保存
- 最新ログに連動した水温、pH、水換え、AI状態の表示
- 今日の管理タスクのチェック状態保存
- 写真投稿風のコミュニティ画面
- 投稿といいね数のブラウザ保存
- 投稿と水槽・池のひも付け
- 投稿時の画像選択、プレビュー、ブラウザ保存
- 投稿画像の差し替えと投稿削除
- 水槽プロフィール内の関連投稿表示
- 水槽ごとの画像アルバム表示
- アルバム写真を水槽プロフィールの表紙に設定
- 投稿画像からAI分析画面へ送る導線
- コミュニティ投稿の水槽別フィルター
- 状態選択からのAI分析デモ
- 飼育ガイドとPR枠の表示
- スマホ幅対応のレスポンシブUI
- PWA用の `manifest.webmanifest` と `sw.js`
