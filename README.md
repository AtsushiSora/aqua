# AquaNote Prototype

水槽・池の管理、写真投稿、AI分析、飼育ガイド、収益化導線をまとめた静的プロトタイプです。

## 開き方

`index.html` をブラウザで開くと動きます。

## 入っている機能

- 水槽・池の管理ダッシュボード
- 複数の水槽・池の登録と切り替え
- 水槽プロフィールの編集と削除
- 水温、pH、メンテナンス記録の入力とブラウザ保存
- 選択中の水槽・池ごとの管理ログ保存
- 最新ログに連動した水温、pH、水換え、AI状態の表示
- 今日の管理タスクのチェック状態保存
- 写真投稿風のコミュニティ画面
- 投稿といいね数のブラウザ保存
- 状態選択からのAI分析デモ
- 飼育ガイドとPR枠の表示
- スマホ幅対応のレスポンシブUI
- PWA用の `manifest.webmanifest` と `sw.js`
