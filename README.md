# AquaNote Prototype

水槽・池の管理、写真投稿、AI分析、飼育ガイド、収益化導線をまとめた静的プロトタイプです。

## 開き方

`index.html` をブラウザで開くと動きます。

## 入っている機能

- 水槽・池の管理ダッシュボード
- 水温、pH、メンテナンス記録の入力
- 写真投稿風のコミュニティ画面
- 状態選択からのAI分析デモ
- 飼育ガイドとPR枠の表示
- スマホ幅対応のレスポンシブUI
- PWA用の `manifest.webmanifest` と `sw.js`
