Rehearsal

通知リハーサル手順

  1. 鍵と環境変数 VAPID公開鍵をブラウザ設定、秘密鍵をNetlify環境変数に入れる
  2. dry-run確認 まずdry-runのまま通知予約が作られることを配信ログで確認する
  3. 送信有効化 NOTIFICATION_DELIVERY_DRY_RUN=falseにして、直近のリマインダーを同期する
  4. 結果確認 配信ログのsent / failed / skippedを確認し、failedは詳細を見て再送予約する

PWA rehearsal

PWA本番リハーサル

  1. 本番URLで開く 公開URLをiPhone SafariとAndroid Chromeで開き、ログインと初期表示を確認する
  2. ホーム追加 インストールボタンまたはホーム画面追加から保存し、アプリアイコンで起動する
  3. 通知同期 通知許可、Push購読、dry-run予約、dry-run解除後の受信を配信ログで確認する
  4. オフライン復帰 機内モードで再読み込みし、キャッシュ画面またはオフラインページが出ることを確認する
  5. 4モード確認 ベーシック、かんたん、管理重視、投稿重視モードを切り替え、ホームで主要操作を試す
  6. 画像カスタム 背景画像とボタン背面画像を設定し、各モードで文字が読めることを確認する

First user guide

モニター参加者への案内

  1. 新規登録またはログインをして、プロフィールを保存する
  2. 自分の水槽を1つ登録し、写真をTOPに設定する
  3. 水温、pH、水換え、フィルター掃除を1回ずつ記録する
  4. 投稿またはアルバムに写真を1枚追加する
  5. ベーシック、かんたん、管理重視、投稿重視の表示を切り替えて感想を残す

Before launch

本番前セットアップ

  1. Supabase SQL supabase/schema.sql を実行。既存プロジェクトは supabase/migrations/20260602_remove_glance_ui_mode.sql も実行。 確認場所: アカウント / Supabase Auth
  2. Storage 写真・動画用のStorage bucketを作成し、投稿/水槽画像のアップロードを確認。 確認場所: 水槽管理 / コミュニティ投稿
  3. AI Gateway Netlifyに OPENAI_BASE_URL / OPENAI_API_KEY を設定し、AI API検証でGateway経路を確認。 確認場所: AI分析 / AI API検証
  4. 通知 Pushを使う場合はVAPID公開鍵/秘密鍵、SUPABASE_SERVICE_ROLE_KEY、dry-run解除を確認。 確認場所: アカウント / 通知本番チェック
  5. PWA実機QA 本番URLでログイン、ホーム追加、通知、オフライン、4モード、画像カスタムを記録し、JSONを書き出す。 確認場所: アカウント / PWA実機テスト結果
